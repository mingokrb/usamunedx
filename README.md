# UsamuneDX
## usamunedx
A faithful recreation of the **[Usamune Practice ROM](https://sites.google.com/view/supermario64/usamunepj/usamunerom)** in **[sm64coopdx](https://github.com/coop-deluxe/sm64coopdx)** as a Lua mod, with a few extra features.

You can also easily add new menus if you got basic Lua knowledge.

> [!IMPORTANT]
> **Please check the [official Usamune ROM Manual](https://goo.gl/NTR61H) before using this mod** if you're not familiar with how the Usamune Practice ROM works.

---
## New Features
* New **[DELUX]** category with some cool new functions, such as:
  - **[HINTS]**: Shows a brief description of the current category/function;
  - **[ARWLRP]**: Moves the selection arrow more smoothly (linear interpolation)
* Separate **[INPUT]** category for input display, with more customization options such as:
  - Display buttons from Right-to-Left;
  - Set visibility of buttons and stick individually;
  - New (optional) graphics for **X**, **Y**, **L** and **D-Pad** buttons display
